# Game Translate

Перевод текста из игр в реальном времени для Windows. Выделяешь область экрана, где появляются диалоги или квесты, а программа сама распознаёт текст и показывает перевод в полупрозрачном окне поверх игры. Окно пропускает клики, поэтому играть не мешает.

- Распознавание текста встроенным в Windows OCR (`Windows.Media.Ocr`): локально, быстро и бесплатно.
- Перевод через Gemini API с учётом контекста предыдущих реплик. Если Gemini недоступен, программа сама переключается на Google Translate.
- Перевод показывается лентой, как в чате: имя говорящего или название квеста выводится заголовком, текст разбит на абзацы, новые реплики появляются внизу, старые постепенно бледнеют.
- Живой режим сам замечает новый текст и переводит его, когда фраза перестала меняться. Поэтому текст, который печатается по буквам, не переводится на середине.
- Окно перевода скрыто от захвата экрана: его не видно на скриншотах и в записи, и программа не переводит сама себя.

## Требования

- Windows 10 2004 или новее, либо Windows 11.
- Языковой пакет Windows для языка игры. Английский обычно уже установлен. Другие языки добавляются в «Параметры → Время и язык → Язык и регион → Добавить язык».
- Ключ Gemini API (необязательно). Без него перевод идёт через Google Translate.
- Игра в режиме «окно без рамки» (Borderless). В эксклюзивном полноэкранном режиме окно перевода поверх игры не видно, но его можно вынести на второй монитор (`Ctrl+Alt+W`).

## Сборка

Нужны [Rust](https://rustup.rs) (toolchain `stable-x86_64-pc-windows-msvc`) и Visual Studio Build Tools с компонентом «Desktop development with C++».

```powershell
winget install Microsoft.VisualStudio.2022.BuildTools --override "--wait --passive --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
winget install Rustlang.Rustup

git clone <url-репозитория>
cd game-translate
cargo build --release
```

Готовая программа будет в `target\release\game-translate.exe`. Её можно скопировать в любую папку: настройки и журнал создаются рядом с exe.

## Ключ Gemini

Ключ создаётся в [Google AI Studio](https://aistudio.google.com/apikey). Сохрани его в переменную окружения пользователя: команда спросит ключ и не выведет его на экран.

```powershell
$k = Read-Host "Gemini API key" -AsSecureString; [Environment]::SetEnvironmentVariable("GEMINI_API_KEY", [Net.NetworkCredential]::new("", $k).Password, "User"); Remove-Variable k
```

Gemini API доступен не во всех странах. Если в окне программы появляется ошибка `User location is not supported`, запросы к `generativelanguage.googleapis.com` нужно пускать через VPN или прокси (см. `proxy` в настройках). Пока Gemini недоступен, в режиме `auto` перевод идёт через Google Translate.

## Использование

Запусти `game-translate.exe`. Слева вверху появится подсказка по горячим клавишам.

| Клавиши | Действие |
|---|---|
| `Ctrl+Alt+R` | Выбрать область: протянуть рамку мышью. `Esc` или правая кнопка мыши отменяют выбор |
| `Ctrl+Alt+T` | Живой перевод: включить или выключить |
| `Ctrl+Alt+S` | Перевести область один раз |
| `Ctrl+Alt+G` | Отправить область в Gemini картинкой, если OCR не справляется со шрифтом |
| `Ctrl+Alt+H` | Скрыть или показать окно перевода |
| `Ctrl+Alt+W` | Режим перемещения: окно перевода можно перетащить мышью (например, на второй монитор) и растянуть за края. Повторное нажатие закрепляет его на новом месте |
| `Ctrl+Alt+N` | Вернуть окно перевода к выбранной области |
| `Ctrl+Alt+Q` | Выход |

Обычно окно перевода пропускает клики мыши сквозь себя и стоит под областью или над ней. Закреплённое через `Ctrl+Alt+W` окно остаётся на своём месте и после перезапуска. Высота, до которой его растянули, становится пределом: лента растёт вниз до неё, а старые реплики уходят.

Перевод лучше работает, когда область небольшая и захватывает только нужный текст, например окно диалога или блок квеста, а не весь экран.

## Настройки

При первом запуске рядом с exe создаётся `config.toml`. Выбранная область сохраняется в нём автоматически.

| Параметр | По умолчанию | Описание |
|---|---|---|
| `engine` | `"auto"` | `auto`: Gemini, а если не отвечает, то Google. `gemini`: только Gemini. `google`: только Google Translate |
| `model` | `"gemini-flash-lite-latest"` | Модель Gemini |
| `gemini_thinking` | `"minimal"` | Уровень «размышления» модели. Пустая строка оставляет значение по умолчанию модели. Для перевода размышление не нужно и только добавляет задержку |
| `gemini_timeout_ms` | `6000` | Сколько ждать Gemini, прежде чем переводить через Google |
| `proxy` | `""` | Прокси для запросов, например `http://127.0.0.1:8080`. Пустая строка означает системный прокси Windows |
| `target_language` | `"Russian"` | Язык перевода для Gemini |
| `target_code` | `"ru"` | Тот же язык в виде ISO-кода для Google Translate |
| `ocr_language` | `"en-US"` | Язык распознавания текста (нужен установленный языковой пакет Windows) |
| `poll_ms` | `400` | Как часто проверять область в живом режиме |
| `font_size` | `22` | Размер шрифта перевода |
| `opacity` | `225` | Непрозрачность окна перевода, от 0 до 255 |
| `history_size` | `5` | Сколько последних реплик держать в ленте |
| `max_requests_per_phrase` | `3` | Сколько раз в живом режиме можно заново перевести одну и ту же реплику, если OCR прочитал её чуть иначе (появилось имя говорящего, исправилась буква). Перевод обновляется в той же записи ленты. Дальше остаётся уже показанный перевод |
| `max_height_percent` | `45` | Максимальная высота окна в процентах от высоты экрана, пока оно не закреплено |
| `overlay_rect` | нет | Позиция и размер закреплённого окна перевода. Записывается через `Ctrl+Alt+W`, удаляется через `Ctrl+Alt+N` |

## Журнал

Рядом с exe пишется `game-translate.log`: распознанный текст, отправленные на перевод фразы и ошибки. Журнал пересоздаётся при каждом запуске.

## Устройство

| Файл | Назначение |
|---|---|
| `src/main.rs` | Горячие клавиши и цикл сообщений Windows |
| `src/selector.rs` | Выбор области мышью |
| `src/capture.rs` | Захват области экрана (GDI) и определение изменений |
| `src/ocr.rs` | Windows OCR и группировка строк в абзацы |
| `src/text.rs` | Модель реплики: заголовки и абзацы |
| `src/translate.rs` | Gemini и Google Translate |
| `src/worker.rs` | Фоновый поток: живой режим, кэш, контекст |
| `src/overlay.rs` | Окно перевода в виде ленты |
| `src/config.rs` | Настройки `config.toml` |

## Тесты

```powershell
cargo test
```

Тесты, которым нужны сеть или экран, помечены `#[ignore]` и запускаются отдельно:

```powershell
cargo test -- --ignored --nocapture translates_with_google
```
